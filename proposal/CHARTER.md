# Project Charter — vibe-study-bootcamp

> Open-Source Vibe Coding × Self-Study Hub
> Created: 2026-08 · Author: Saba (葉) Yip

## Vision

**每個人都能用 AI + multi-agent + vibe coding 系統性自學任何學科。**

呢個 project 係 100% open-source framework，目標係建立世界上最大、最 high-quality 嘅 self-study 課程庫，覆蓋工程、物理、人文、社科、醫學。

## Mission Statement

我哋相信：
- 知識應該係 free 同 accessible 俾所有人
- AI 可以大幅降低 high-quality education 嘅成本
- Multi-agent + strict quality gates = production-grade 內容
- Bilingual (中英對照) 教育對香港同國際學生都有好處
- Open source + community = 可持續發展

## Core Principles

### 1. 質量第一 (Quality First)
- 每個 course 必須通過 10-gate quality rubric
- 拒絕 template 填空 / placeholder / generic 廢話
- 真實 scholar 引用 + primary source
- **不通過不推送** — 嚴格 enforcement

### 2. 公開透明 (Open & Transparent)
- 全部 code open-source (MIT License)
- 全部 quality gate logs public
- 全部 methodology documented
- 鼓勵 community contribution

### 3. 雙語並重 (Bilingual)
- 中英對照 內容
- 香港 dual-language 環境
- International accessibility

### 4. Vibe Coding Friendly
- AI 自動 generate 初稿
- Human + AI collaboration
- Strict quality gates
- Iterative improvement

## Technical Architecture

### Stack
- **Backend:** Python 3.11+ (multi-agent scripts)
- **Frontend:** React 19 + TypeScript + Vite + Tailwind v4
- **Quality:** 10-gate rubric
- **Data:** JSON
- **Deploy:** Static PWA

### Multi-Agent Pipeline
5 個 agents 各自有 strict 職責 + quality gate：
1. Researcher — Primary sources only
2. Data Extractor — Verifiable facts only
3. Engineer — Specific content only
4. Diagram — Distinct diagrams only
5. Professor Supervisor — APPROVED/REVISE/REJECT
