# Vibe Coding Workflow

> How to use AI + multi-agent pipeline to generate high-quality self-study content

## 哲學 (Philosophy)

**Vibe Coding** = 與 AI 協作嘅 coding/learning 模式，強調：
- 🤖 AI 做 heavy lifting (generate, draft, search)
- 👤 人做 quality control (review, refine, approve)
- 🔄 快速 iterate 至 quality bar
- 💯 結果導向 (final output 最重要)

---

## 7 Phases

```
Phase 1: PLAN         →  揀 topic, define 5MM/3DG/10Q skeleton
Phase 2: RESEARCH     →  AI 查 primary sources
Phase 3: EXTRACT      →  AI 提取 objectives/themes
Phase 4: PRODUCE      →  AI 寫 5MM/3DG/10Q 內容
Phase 5: DIAGRAM      →  AI 加 5 Mermaid 圖
Phase 6: REVIEW       →  Professor Supervisor 跑 quality gates
Phase 7: PUBLISH      →  Auto push to GitHub
```

**Total time per course: 1-2 hours** (vs 2-3 weeks manual)

---

## Quality Control 守則

### DO ✅
- 每次 produce 後立即 run Professor Supervisor
- APPROVED 之前唔好 commit
- 用真實 scholar names (verify with Researcher)
- 寫 Chinese 同 English 兩個版本
- 用 LaTeX equations

### DON'T ❌
- 用 template placeholders
- Skip quality gates
- 接受 REVISE status
- 假 data / generic 廢話
- Pseudocode

---

## Scaling Up

- **Single Person (1 bootcamp)**: 1 course/day
- **Small Team (2-5)**: 5-10 courses/day
- **Community (10+)**: 50+ courses/day
